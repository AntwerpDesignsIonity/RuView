ESP32 Provisioning

Flash firmware and write WiFi credentials to all connected ESP32-S3 boards.

Security: Flashing requires USB access and will overwrite firmware. Run the generated command in a terminal on the hub (this Pi). The WiFi password is only used in the command you copy — it is never sent to the server.

1. WiFi & Hub Configuration

Hub IP auto-detected from /health. Change only if this Pi will use a different IP (e.g. static reservation on your router).
